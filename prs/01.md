## Purpose

A check of the live site showed it was missing the standard safety rules that browsers follow, and that every visit re-downloaded the same large files (the 3D map library is about 250 KB compressed). It also had one lookup (`/api/nearby`, used by the Stops button) with no limit on how often one person could call it.

## Changes (what you will notice)

No visual change. In plain terms:

- **Safer pages.** The server now sends the usual browser safety rules: only load scripts from Lapan itself, never show Lapan inside someone else's page, always use HTTPS, and share less information when a link is clicked.
- **Faster return visits.** Each file now has a fingerprint, so the browser asks "has this changed?" and gets a tiny "no" instead of downloading it again. Map libraries and icons are remembered for an hour.
- **Fairer use of the nearby-stops lookup.** One person can make 20 fresh lookups a minute on a given server instance, which protects the free map service Lapan relies on. Because there can be several instances, it is a safeguard rather than a hard guarantee. Repeat lookups for the same place are still answered instantly.
- **Optional stronger protection.** If Cloudflare's rate limiting is switched on later (a binding called `RATE_LIMITER`, described in the README), Lapan will use it. Nothing changes until then.

## Impact

- No new paid services, API calls, permissions or settings.
- **One thing to know about HTTPS.** After a first visit, browsers will insist on HTTPS for lapan-malaysia.com for a year (not for sub-domains). This is normal and wanted, but it means HTTPS must always keep working.
- **One thing to know about the safety rules.** If Lapan later starts using a new outside service (fonts, tiles, a new API), its address must be added to the list in `worker/assets.js`, or browsers will block it. This is written in the README.
- Optional Cloudflare rate limiting needs a setting in your Cloudflare account. Check your plan before turning it on.
- Not fixed, because it needs hosting access: `www.lapan-malaysia.com` fails its secure connection, HTTP redirects with a temporary rather than permanent redirect, and there is no `security.txt` contact file.
