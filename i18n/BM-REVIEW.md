# Bahasa Malaysia review sheet

Please read the Malay column as a Malaysian driver would. Mark anything that sounds stiff, wrong, or unlike how people really say it, and suggest the wording you would use. {n}, {name} and similar are filled in by the app. Text in <angle brackets> is formatting and must stay.

**Terms used throughout** (change one and tell me, so it changes everywhere): route = laluan; speed limit = had laju; km/h = km/j; highway = lebuh raya; toll = tol; exit = keluar; roundabout = bulatan; U-turn = pusingan U; Home Screen = Skrin Utama (Apple's own term); live = masa nyata; settings = tetapan; destination = destinasi.
